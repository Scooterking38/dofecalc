# dofecalc
A Python-based calculator with various mathematical operations.

## Features
* Perform arithmetic operations such as addition, subtraction, multiplication, and division
* Handles invalid inputs by prompting users to try again
* Designed for simplicity and ease of use

## Tech Stack
* Language: Python
* Files:
	+ `main.py`: The main script that handles user input and calculations
	+ Other files are supporting scripts (diceroller.py, higherorlower.py, etc.)

## Installation and Getting Started
1. Clone the repository using `git clone https://github.com/your-username/dofecalc.git`
2. Install Python 3.x (if not already installed)
3. Run `python main.py` to start the calculator
