# dofecalc

A collection of simple Python scripts for various interactive games and calculations.

## Architecture Overview

The `dofecalc` repository contains multiple Python scripts, each serving a different purpose:

- **diceroller.py**: A script that simulates rolling a dice with a user-defined number of sides.
- **higherorlower.py**: A game where the user tries to guess a randomly generated number between 1 and 100 with the lowest score possible.
- **main.py, main2.py, main3.py**: Three versions of a basic calculator that performs addition, subtraction, multiplication, and division based on user input.
- **numberguesser.py**: A simple number guessing game where the user tries to guess a randomly generated number between 1 and 10.

Each script is independent and can be run separately. They all use basic Python constructs such as loops, conditionals, and functions to provide interactive user experiences.

## Tech Stack

- **Programming Language**: Python
- **Libraries/Frameworks**:
  - `random`: Used for generating random numbers in several scripts.
  - No external libraries are used; the scripts rely solely on built-in Python functionality.

## Getting Started / Setup Guide

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/yourusername/dofecalc.git
   cd dofecalc
   ```

2. **Run a Script**:
   Each script can be executed individually using Python. For example, to run the dice roller, use:
   ```bash
   python diceroller.py
   ```
   Similarly, you can run other scripts like `higherorlower.py`, `main.py`, etc.

3. **Explore and Modify**:
   Feel free to explore the code in each script. You can modify them to add new features or change existing functionalities as per your requirements.

4. **Contribute (Optional)**:
   If you have improvements or additional scripts to contribute, feel free to fork the repository, make changes, and submit a pull request.

This setup provides a straightforward way to interact with basic Python scripts for entertainment and educational purposes.
